# AI UNIVERSAL SIGNAL RADAR

MAIN MARKET · NON-OTC · M1 · Telegram Mini App.

The root frontend is a single-file application in index.html. It connects to the separately deployed API at https://ai-signal-radar-main-market.onrender.com and requires Telegram Mini App authentication.

Supported pairs: EUR/USD, AUD/USD, EUR/GBP, GBP/JPY, EUR/JPY, GBP/USD.

Signals are advisory only. No broker order execution. Never use simulated prices or random signals. See PROJECT-HANDOFF.md for current architecture and known limitations.
